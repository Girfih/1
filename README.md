# Python Game Pack (GUI)

Коллекция мини-игр с графическим интерфейсом (Tkinter).

## Что внутри

- 🃏 Карты (старшая карта)
- 🎰 Рулетка (цвет или число)
- ♠️ 21 (Blackjack)
- 🔢 Угадай число
- ✊ Камень-ножницы-бумага
- 🎲 Дуэль на костях
- 🎰 Слоты

## Фишки приложения

- Единый профиль игрока: имя, банк, статистика (игры, победы, winrate)
- Ставки для всех игр
- Лог последних раундов в интерфейсе
- Авто-восстановление банка до 200 при полном проигрыше

## Запуск

```bash
python3 casino_games.py
```

> Требуется стандартный Tkinter (обычно уже входит в Python).
